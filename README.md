# Full Stack Developer Capstone Project

## Project Name
**Full Stack Developer Capstone Project**

## Description
This project is a full-stack car dealership application. It provides dealership information, car makes and models, user authentication, and customer reviews.

## Technologies Used
- Frontend: React
- Backend: Django and Django REST Framework
- Database: As configured in the project
- Testing: cURL and browser-based testing
- CI/CD: GitHub Actions

## Main Features
- View dealerships and filter dealerships by state
- View dealership details and customer reviews
- Register, log in, and log out
- Submit dealership reviews
- View car makes and models
- Analyze review sentiment

## Project Structure
- `server/` — backend and frontend application files
- `server/frontend/` — frontend components and static pages
- `.github/workflows/` — CI/CD workflow files, if configured

## Running the Project
Follow the setup instructions and environment requirements provided by the project repository. Configure the required environment variables before starting the application.
